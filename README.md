# Graduate-Employment-Data-Analysis
A Python data pipeline to analyze real-world graduate employment statistics using Pandas, Matplotlib, and SQLite.
📊 Real-World Graduate Employment & Salary Analysis
🎯 Project Overview
This project focuses on the acquisition, processing, and visualization of real-world employment data for college graduates. By sourcing authentic data from the FiveThirtyEight GitHub repository, we identified "Golden Majors" that offer both high financial returns and strong job security.

🛠️ Tech Stack
Language: Python 3.13
Data Acquisition: urllib.request
Data Processing: pandas
Data Visualization: matplotlib
Data Management: sqlite3
🚀 How to Run
Clone this repository to your local machine.
Ensure you have the required libraries installed: pip install pandas matplotlib
Run the main script:
python "Web crawler + data analysis.py"
📈 Key Visualizations
The script generates 4 professional charts analyzing salary rankings, industry comparisons, and a "Golden Major Matrix".
